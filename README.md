# Gamma Spectroscopy Analysis

Ez a repository a hordós gamma-spektroszkópiai mérések feldolgozására szolgál.

## Workflow

1. MCA → energia kalibráció
2. Kalibrált spektrum → peak fit
3. Peak fit → plotok

## Struktúra

- data/calibrated → kalibrált spektrumok
- results/peak_fits → illesztési eredmények
- plots → kész ábrák
- src → feldolgozó kódok
